# KRGN Portfolio

Selected modules from a personal productivity and data analytics system built in Python.

## Modules

### [CV Generator](cv-generator/)
A Python tool that generates professional, ATS-friendly CVs from structured JSON data using a **master/derivative pattern**. One master profile per person, unlimited tailored CVs for different job applications. Output as PDF via ReportLab.

This portfolio showcases real, working software built to solve practical problems. Each module was developed to address a specific personal or professional need, then refined through continuous use.
